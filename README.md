Task 1: Scholarship Eligibility

A university offers a scholarship to students who have either obtained 80% or above marks OR have a family income below Rs. 50,000. Write a C program that takes marks and family income as input using scanf(). Use relational operators, the OR (||) operator, and if-else to determine whether the student qualifies for the scholarship.

task2.c

Task 2: Library Fine Calculator

A library wants to calculate a student's fine based on the number of late days. Ask the user to enter the number of late days using scanf().

If the student has 0 days, display "No Fine".
If the late days are 1–5, display "Fine: Rs. 50".
If the late days are 6–10, display "Fine: Rs. 100".
For more than 10 days, display "Fine: Rs. 200".

Use relational operators and nested if-else conditions.

Task 3: Student Name Input Using fgets()

A student registration system needs to collect a student's name. Write a C program that uses fgets() to take the student's full name, including spaces. Then use puts() to display a message containing the entered name.

The program should demonstrate the difference between taking a complete line of text and a single character.
